# SillyTavern — Custom Models

基于 [LenAnderson/SillyTavern-CustomModels](https://github.com/LenAnderson/SillyTavern-CustomModels) 的维护分支。

为 **OpenAI、Claude、Google/Gemini，以及自定义（兼容 OpenAI）** 连接添加可编辑的模型列表。

## 安装

在酒馆的「扩展程序 → 安装扩展」中粘贴：

```text
https://github.com/luoyuewuyi/SillyTavern-CustomModels
```

安装后刷新浏览器页面，并等待酒馆初始化完成。

### 已安装上游原版时

两个仓库的目录名相同，直接再次安装可能提示“已存在”，而旧版的更新按钮仍会跟随旧仓库。

1. 先备份自己的酒馆设置/已有自定义模型列表。
2. 在扩展管理中卸载 **LenAnderson 的 Custom Models**，然后使用上面的链接安装此分支。
3. 刷新页面。请不要把两个版本改名后同时启用。

也可以由熟悉服务器操作的人，在确认是该插件的 Git 目录后，将其 `origin` 改为本仓库再更新；不要在酒馆主程序目录执行此操作。

## 使用

1. 打开「API 连接」，选择「聊天补全」。
2. 来源选择「自定义（兼容 OpenAI）」时，**“输入模型名”标题旁**会出现编辑按钮。
3. 点击按钮，每行填写一个完整模型 ID，点击 **Save**。
4. 在下方“可用模型”的 **Custom Models** 分组中选择要使用的模型。保存列表本身不会自动切换模型。

OpenAI、Claude、Google 的按钮仍位于各自的模型标题旁。

模型 ID 必须是 API 服务实际支持的名称。本插件只扩展界面列表，**不会让不存在的模型变得可用，不会提供 API Key、订阅或额度**。

## 1.4.0 的修改

- 支持 `custom` 来源，并适配其不同的模型输入框/下拉框布局。
- 兼容原版 `extension_settings.customModels` 数据，保留旧来源的模型列表。
- 去掉每行前后空白、空行与重复项。
- 找不到某一来源的控件时跳过该来源，不让整个插件报错退出。
- 使用可键盘操作的原生按钮，并避免重复注入。
- 不再截断模型选择的 `change` 事件，让酒馆能正常更新实际模型。
- 自定义 API 刷新模型列表后恢复本插件的分组；以酒馆的模型输入框为准，不用旧选择覆盖切换后的连接配置。

## 数据与权限

- 模型列表保存在当前酒馆用户的扩展设置中，不按每个自定义端点单独分组。
- 不读取 API Key，不发送模型请求，不上传聊天，不安装其他插件。
- 移除列表中的某个 ID 不会擅自修改已经输入的实际模型名；需要切换模型时请明确选择或编辑输入框。
- 保存仍使用酒馆原生的防抖设置接口。保存后请稍候再刷新，避免未写入的修改丢失。

## 验证边界

按 SillyTavern **1.18.0** 的实际控件结构及模型输入/选择事件约定进行了核对；通过 7 项 DOM 回归检查，以及桌面和 390px 窄屏下的隔离浏览器交互检查：按钮、保存、选择、API 列表刷新、页面重载和取消。

这些测试没有发送真实模型请求，也没有替换原服务器上的插件；并非宣称已经在所有酒馆版本、主题或浏览器上验证通过。
